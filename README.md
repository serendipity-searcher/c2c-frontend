# Comment to Conversation (frontend)

Install [bun](https://bun.com/)

```sh
curl -fsSL https://bun.sh/install | bash
```

## Project Setup

```sh
bun install
```

### Compile and Hot-Reload for Development

```sh
bun dev
```

### Compile and Minify for Production

```sh
bun run build
```

### Lint with [ESLint](https://eslint.org/)

```sh
bun lint
```
